# EQLSaK Build Advisor
## Plan your trio. Know your strengths. Learn from every hunt.

EQLSaK Build Advisor is a **free companion for EverQuest Legends players** who want clear build advice and useful combat information in one place.

Choose your classes, tell the Advisor how you like to play, and see which options fit your goals. Its built-in rules explain the reasons behind each recommendation. **No AI subscription, API key, or cloud model is needed.**

### 🧭 Start with your play style

Enter your class combination, level, and preferred role. Plan for solo play, a duo, or a group. Tell the Advisor how much healing, enemy control, movement, and hands-on effort you want in your build.

### ✨ Find out why a class fits

Compare ranked third-class choices. Press **See why** for a clear report with bullet points covering strengths, weak spots, tradeoffs, and other options. Check the source labels and save the report as a text file.

The advice uses editable local rules. Matching inputs and rules give the same results, so you can see how a change affects your plan.

### 👥 See the whole party

Compare **up to four players, each with their own trio**. Class icons and strength charts show where your party has good coverage and where it may need help. Save up to four builds and share build files with friends.

### 🗺️ Choose where and what to hunt

Search the zone list, review the available hunt advice, and weigh your party's fit. Follow **Open zone guide** to the companion website for supported map and zone details.

Use the faction tracker to enter or import your standing, set a goal, and view your progress. Read which listed hunts may help one faction while hurting another.

### ⚔️ Bring your combat log to life

The Windows app can search common EQL log folders and let you choose the character log to watch. Live gauges and spike charts show recorded damage, critical hits, damage-over-time activity, and healing.

Spell activity cards and configurable timers help you track effects and refresh cues. Load a saved log to review recorded totals or replay its last minute. A built-in demo lets you explore the displays before loading your own log.

### 💎 Learn from each trip

Set loot goals and review the gains recorded during your hunt. When a zone exit is detected—or you report leaving—the trip report offers suggestions for your next run. Add a note for a drop you actually saw but missed, and save the report for later.

### 🔄 Refresh information when you choose

Build planning works offline. In the Windows app, optional online checks can flag changes to the saved information sources. Review a rule update before applying it, and roll back to the previous rules if needed.

### ❤️ Free to use. Open to improvements.

All features in this release are free. The source code is available on GitHub for suggestions, fixes, and forks. Donations are optional; no donation page is configured yet.

**Download, source code, and feedback:** https://github.com/venducati/eqlsak-build-advisor

**Before you start:** This is an unsigned Windows 64-bit community preview. A portable browser version is also available, with some Windows-only features. Planning scores are estimates. The meter can only show information found in your log or entered by you; it does not read exact live health from game memory. Spell timers depend on the messages and durations available. An unmet loot goal does not prove that an item dropped. Online checks and website links need internet access.
