# Security and privacy reports

Do not post credentials, real player chat, complete logs, or exploit details in a public issue. Use invented or redacted examples for ordinary bugs.

For a suspected vulnerability, use GitHub's **Security → Report a vulnerability** option when it is enabled. If unavailable, open an issue asking for a private contact without disclosing the sensitive details.

Version 1.6.1 is an unsigned community preview. No security audit or clean-machine certification is claimed. The app reads user-selected logs and optional source pages; it does not inject into the game or upload player logs for inference.
